# Модуль через TDD

1. Ветка от свежего `main`: `git switch main && git pull --rebase --autostash && git switch -c feat/<issue>-<кратко>`.
2. Тест рядом с кодом: `packages/core/src/<модуль>/<имя>.test.ts`. Эталоны — из данных набора (`data/kit/`) или README
   набора, с комментарием, откуда взяты. Запустить `pnpm test` — тест должен упасть.
3. Коммит только теста: `test(<модуль>): <что проверяется> (падающий тест)`.
4. Реализация до зелёного `pnpm verify`; комментарии объясняют «почему», а не «что».
5. Экспорт из `packages/core/src/index.ts`.
6. Коммит реализации: `feat(<модуль>): ...` с телом «что и зачем».
7. Синхронизация с `main` — только merge (`git merge --no-ff origin/main`), не rebase уже отправленной ветки.
8. Pull request по шаблону `.github/pull_request_template.md`; слияние — `gh pr merge N --merge --delete-branch`
   только после зелёной проверки.

Правила коммитов — AGENTS.md: без служебных подписей инструментов, без эмодзи, без ключей.
