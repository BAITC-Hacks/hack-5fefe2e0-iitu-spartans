# Изменение маршрутизатора

1. Промпт строится только из данных набора (`data/kit/scenarios.json`: описания, `not_this_if`, примеры). Тексты
   `dev_utterances.json` в промпт не добавлять — это утечка проверочных данных; хардкод реплик запрещён ТЗ.
2. Промпт должен оставаться детерминированным (тест `router.test.ts`): неизменный каталог в начале кэшируется моделью.
3. Любое изменение формата решения — сначала в контракте `packages/core/src/contracts/route-decision.ts` и его тестах;
   сервис FastAPI (`ROUTER_URL`) отвечает по тому же контракту.
4. После изменения — замер на размеченных репликах набора и сравнение с прошлым результатом: primary accuracy,
   full match, полнота мульти-намерений, медиана задержки. Регресс — откатить.
5. Сценарий вне каталога ответ отклоняет (`unknown_scenario`) — не ослаблять эту проверку.
